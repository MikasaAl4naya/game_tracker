# SpeedTest CLI: замер скорости скачивания файла по URL

Консольный скрипт для замера скорости загрузки файла по HTTP/HTTPS. Запускается на Python 3.10+, выполняет последовательные запросы и рассчитывает среднюю скорость скачивания в Мбит/с.

---

## Требования

- Python 3.10+ (проверено на версиях 3.10–3.14).
- Сторонние библиотеки не нужны, ставить что-либо через pip не требуется.

Скрипт использует только стандартную библиотеку:
- `urllib.request`, `urllib.error`, `urllib.parse` — отправка HTTP-запросов и обработка сетевых ошибок;
- `argparse` — разбор аргументов командной строки и валидация;
- `time` — замер времени через `time.perf_counter()`;
- `dataclasses` — структуры данных для результатов и итоговой статистики;
- `socket` — обработка таймаутов на уровне сокетов.

---

## Как устроен скрипт

1. **Последовательные синхронные запросы.** Запросы идут строго по очереди: следующий начинается только тогда, когда предыдущий выкачан до конца. Никакой асинхронности и фоновых потоков (без `asyncio` и `threading`).
2. **Чтение потоком порциями по 64 КБ.** Чтобы замерить скорость, нужно скачать файл целиком. Если считывать тело ответа одним вызовом `response.read()`, весь файл окажется в оперативной памяти, что на больших файлах приведет к `MemoryError`. Поэтому скрипт читает данные чанками по 64 КиБ (65 536 байт) и не накапливает их в памяти, а лишь ведет счетчик байтов. Расход памяти остается постоянным ($O(1)$), а данные честно проходят через сетевой стек.
3. **Замер через `time.perf_counter()`.** Монотонный таймер высокой точности, который не сбивается при системных корректировках часов (NTP).
4. **Заголовок `User-Agent: Mozilla/5.0`.** Передается в каждом запросе, чтобы веб-серверы и CDN не блокировали скрипт кодом 403 Forbidden.
5. **Обработка сетевых ошибок.** Скрипт перехватывает `HTTPError`, `URLError`, `TimeoutError` и таймауты сокетов. Если отдельный запрос завершился ошибкой, программа не падает со стектрейсом: она выводит сообщение, фиксирует время попытки и переходит к следующему шагу. При остановке по `Ctrl+C` возвращается код 130.
6. **Защита от деления на ноль.** Если все запросы завершились ошибкой или суммарное время оказалось нулевым, итоговая скорость корректно выводится как 0.00 Мбит/с вместо падения с `ZeroDivisionError`.

## Примеры запуска

### Базовый запуск (10 запросов по умолчанию)

```bash
python speedtest.py https://speed.cloudflare.com/__down?bytes=10000000
```

### Указать количество запросов (`-n` или `--num-requests`)

```bash
# 5 последовательных запросов
python speedtest.py https://speed.cloudflare.com/__down?bytes=5000000 -n 5

# Длинная форма флага
python speedtest.py https://speed.cloudflare.com/__down?bytes=5000000 --num-requests 3
```

### Дополнительные параметры

```bash
# Таймаут на один запрос в 15 секунд (-t / --timeout)
python speedtest.py https://speed.cloudflare.com/__down?bytes=10000000 -n 5 -t 15.0

# Справка по всем доступным флагам
python speedtest.py --help
```

## Единицы измерения скорости и логика расчёта

Размер файлов обычно измеряют в байтах и мегабайтах (МБ), а пропускную способность сети — в **мегабитах в секунду (Мбит/с, Mbps)**.

### Формула

$$\text{Скорость (Мбит/с)} = \frac{\text{Общий объём данных (в байтах)}}{\text{Общее время (в секундах)}} \times \frac{8}{1\,000\,000}$$

В коде:
```python
avg_speed_mbps = (total_bytes / total_duration_sec) * 8 / 1_000_000
```

### Пояснение шагов расчета:

1. **Перевод байтов в биты ($\times 8$).** В одном байте 8 бит ($1\text{ Байт} = 8\text{ бит}$). Скорость каналов связи измеряют в битах, поэтому сначала скачанный объем переводится в биты:
   $$\text{Объем в битах} = \text{Объем в байтах} \times 8$$

2. **Расчет базовой скорости ($\div \text{время}$).** Разделив биты на чистое время загрузки, получаем скорость в **битах в секунду (бит/с)**:
   $$\text{Скорость (бит/с)} = \frac{\text{Объем в битах}}{\text{Время в секундах}}$$

3. **Перевод в мегабиты ($\div 1\,000\,000$).** В сетевых стандартах приставка «мега-» означает десятичный множитель $10^6$ ($1\text{ Мбит} = 1\,000\,000\text{ бит}$). Для объема файлов на диске принято использовать двоичный мегабайт ($1\text{ МБ (MiB)} = 1024 \times 1024 = 1\,048\,576\text{ байт}$). В консоли объем выводится в привычных МБ ($1024^2$), а сетевая скорость — в стандартных Мбит/с ($10^6$).

4. **Защита от деления на ноль.** Если соединение оборвалось до начала скачивания или ни один запрос не завершился успешно, время составит `0.0` с. Скрипт вернет `0.00 Мбит/с`, не вызывая исключения `ZeroDivisionError`.
